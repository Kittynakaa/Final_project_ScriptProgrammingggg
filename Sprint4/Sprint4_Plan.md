### 1. วัตถุประสงค์และขอบเขตโครงการ (Project Purpose & Scope)

ต่อยอดจากเว็บแดชบอร์ด client-side ใน Sprint 3 โดยยกระดับเว็บให้เป็นแอปพลิเคชันพร้อมใช้งานจริง (Production-ready) เพิ่มฟีเจอร์เด่น **Virtual Try-On ทาสีเล็บจริงบนรูป** และ **Smart Nail Advisory (AI แบบ explainable)** พร้อมปิดช่องโหว่ด้านประสบการณ์ผู้ใช้ที่พบใน Sprint 3 และปิดโครงการด้วยการทดสอบ End-to-End ครบทั้ง 4 Sprint โดยมีขอบเขตดังนี้:

* พัฒนา **Virtual Try-On** บนเว็บ (ฝั่ง client ทั้งหมด) ให้ผู้ใช้เลือกสีแล้ว **เล็บในรูปเปลี่ยนสีได้จริง** โดยลงสีแบบคงแสง-เงาเดิมของเล็บ (luminance-preserving colorize)
* พัฒนาระบบ **ตรวจจับตำแหน่งเล็บอัตโนมัติในเครื่อง** (ไม่พึ่งเซิร์ฟเวอร์/อินเทอร์เน็ต) ด้วยการหาปลายเล็บที่สว่าง-อิ่มตัวต่ำ + Connected Components + PCA หาทิศทาง/ขนาดของเล็บ และกรองด้วยความใกล้เคียงกับผิว
* เพิ่มโหมด **แตะทาเอง (manual touch-up)** เป็นตัวเสริม พร้อมปรับ **ขนาดแปรง / ความเข้ม**, ปุ่ม **ย้อนกลับ / รีเซ็ต / บันทึกรูป**
* พัฒนาฟีเจอร์ **Smart Nail Advisory** — ที่ปรึกษาสีทาเล็บแบบ rule-based + explainable รวมผลวิเคราะห์ (undertone + ITA + ทรง + ความยาวเล็บ) เป็นคำแนะนำเชิงลึก + **% ความมั่นใจ**
* แก้ปัญหา UX ที่พบใน Sprint 3: (1) canvas ถูกซ่อนด้วยกฎ CSS ทำให้สีไม่แสดงบนจอ (ต้องบันทึกรูปก่อนถึงเห็น) (2) สีลงเลยขอบเล็บไปโดนพื้นหลัง
* ตั้งค่า **DevOps / CI-CD**: รัน `pytest` อัตโนมัติทุก push/PR (`ci.yml`) และ Deploy เว็บขึ้น **GitHub Pages** อัตโนมัติ (`static.yml`)
* สรุปปิดโครงการ (Project Wrap-up): ทดสอบระบบ End-to-End ครบทุกองค์ประกอบตั้งแต่ Sprint 1–4 ปรับปรุงคู่มือการใช้งาน (`README.md`, `GITHUB_SETUP.md`) และจัดโครงสร้าง repository ให้ครบตามข้อกำหนดการส่งงาน

### 2. สถาปัตยกรรมระบบ (Modular Architecture & Separation of Concerns)

สถาปัตยกรรมถูกขยายต่อจากสถาปัตยกรรม OOP 3 ชั้นเดิม โดยเพิ่มโมดูลใหม่ของ Sprint 4 เข้าไป ทั้งนี้ยังคงใช้ **Business Logic Layer** และ **Data Access Layer** ชุดเดิมจาก Sprint 1–2 เป็นแกนกลางร่วมกันทั้งฝั่ง CLI และฝั่งเว็บ:

```text
┌────────────────────────────────────────────────────────────────────────┐
│          MODULE 4: VIRTUAL TRY-ON LAYER (CLIENT-SIDE, index.html)       │
│  - detectNails()  : หาปลายเล็บ (bright + low-saturation)                 │
│                     + Connected Components (flood fill) + PCA            │
│                     + กรองด้วยความใกล้เคียงผิว (skin proximity)           │
│  - paintNail()    : ลงสีคงแสง-เงา (HSL luminance colorize)               │
│                     + Dark-pixel Clipping (กันสีเลอะพื้นหลัง)             │
│  - การโต้ตอบ      : ทาอัตโนมัติ / แตะทาเอง / แปรง-ความเข้ม / undo-reset    │
│                     / บันทึกรูป (toDataURL)                               │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│          MODULE 5: SMART NAIL ADVISORY LAYER (AI, EXPLAINABLE)          │
│  - src/advisory.py (NailAdvisory): ทิศทางสี + % ความมั่นใจ               │
│    (คำนวณจากระยะห่าง ITA ถึงเส้นแบ่งโทน) + ฟินิช + เคล็ดลับดูแล          │
│  - พอร์ตขึ้นเว็บ (bilingual TH/EN) — rule-based อธิบายเหตุผลได้ทุกข้อ     │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│          MODULE 6: DEVOPS & CI/CD DEPLOYMENT INFRASTRUCTURE             │
│  - .github/workflows/ci.yml     : รัน pytest อัตโนมัติทุก push/PR        │
│  - .github/workflows/static.yml : Deploy เว็บขึ้น GitHub Pages อัตโนมัติ  │
│  - pytest.ini / requirements.txt : คอนฟิกทดสอบและ Dependency             │
└────────────────────────────────────────────────────────────────────────┘

*(ทั้งหมดนี้ยังเรียกใช้ MODULE 1 DATA ACCESS (DataStore, PaletteRenderer)
  และ MODULE 2 BUSINESS LOGIC (SkinAnalyzer, NailRecommender, ColorApiClient)
  ชุดเดิมจาก Sprint 1–2 เป็นแกนกลางร่วมกัน)*
```

### 💡 Whoops! (ปัญหาที่พบและแนวทางการแก้ไข)

1. **สีทาเล็บแสดงเฉพาะในไฟล์ที่บันทึก แต่ไม่แสดงบนจอ:**
* *ปัญหา:* กฎ CSS `canvas{display:none}` ที่ตั้งไว้เพื่อซ่อน canvas สำหรับการวิเคราะห์ ดันไปซ่อน canvas ของ Virtual Try-On ด้วย ทำให้สีที่ลงอยู่ในหน่วยความจำ (เห็นตอน `toDataURL` บันทึกรูป) แต่ไม่แสดงผลบนหน้าจอ
* *แนวทางแก้ไข:* เปลี่ยนกฎให้เจาะจงเป็น `#canvas{display:none}` (ซ่อนเฉพาะ canvas วิเคราะห์) และกำหนด `#tryCanvas{display:block}` ให้ canvas try-on แสดงบนจอโดยตรง

2. **สีลงเลยขอบเล็บไปโดนพื้นหลัง เป็นวงสีใหญ่:**
* *ปัญหา:* เนื้อเล็บสีชมพูและผิวที่โดนแสงมีค่าความสว่าง/อิ่มตัวใกล้เคียงกันมาก ทำให้วงรีที่ทาคลุมเกินขอบเล็บและเลอะไปบนพื้นหลังมืด (จอคอมพิวเตอร์สีดำ)
* *แนวทางแก้ไข:* เพิ่ม **Dark-pixel Clipping** — ไม่ลงสีบนพิกเซลที่มืดมาก (luminance < 0.30) จึงไม่ทาโดนพื้นหลัง และปรับขนาด/ตำแหน่งวงรีให้อิงขนาดปลายเล็บจริงที่ตรวจพบแล้วไล่ลงตามแนวนิ้ว เสริมด้วยโหมดแตะทาเองสำหรับปรับจุดที่ยังไม่พอดี
